# Commit Message Conventions:

1. Commit Message for new concept.

Description: ** Add the Description of why you did it.

2. Commit Message for concept modification.

Concept Modification: Filename

Description: ** Add the Description here of why you did it.

3. Commit Message for new file of undefined category

New Misc: Filename

Description: ** Add the Description of why you did it.

4. Commit Message for the old file of undefined category.

Old Misc: Filename

Description: ** Add the Description of why you did it.
