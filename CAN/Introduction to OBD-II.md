# Introduction to OBD-II
* OBD Stands for On-Board Diagnostics, and is a vehicles built in self diagnostic system.
* OBD-II Allows the extraction of DTCs (Dignostic Trouble Codes) and real time Data via OBD-II Conncetor.
* Like J1939 and UDS, OBD-II is also a high level CAN Protocol.
* OBD-II is a server-client based protocol.
  * Client Sends requests (usually a testing device)
  * Server (usually an ECU inside a vehicle) Sends the requested Data or DTC (Diagnostic Trouble Codes)
