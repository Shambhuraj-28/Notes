# CAN Bus varients
CAN Bus has many varients following are some examples of them

* Fault tolerant CAN: Better for applications where fault tolerance is high, it is better for non-critical functions such as air conditioing. Although it is being increasingly replaced by LIN Bus (a lower cost suppliment to CAN Bus)

* Classical CAN 2.0: Better for real-time safety-critical data processing and communication.

* CAN FD: Provides higher payload capacity, though adoption remains limited.

* CAN XL: Provides even higher payload capacity than CAN FD and helps bridge gap with automotive ethernet.
