# Introduction to UDS

* UDS Stands for Unified Diagnostic Services.
* it is primarily an Application layer protocol that uses many lower level protocols, CAN is one such protocol.
* it is primarily a request based protocol. i.e. a node sends a request to another node and that node responds back after addressing that request.
* UDS is used for tasks such as diagnostics, firmware updates, routine testing among the others.
* An important salient feature of UDS is that UDS is a client server based protocol where:
  * Tester is a client that sends the request message i.e it requests services from the server.
  * ECU is a server that performs the requests made by client and sends response (positive or negative message).
