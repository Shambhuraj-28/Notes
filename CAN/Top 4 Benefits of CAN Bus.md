# Top 4 Benefits of CAN Bus
The CAN Protocols comes with following 4 Key benefits:
1. **Simple and Low Cost**
  * **Reduced Wiring Complexity**: Since there is a shared common bus to which all devices are connected there is no need to independely connect each pair of related nodes.  
  * **Reduced Harness Weight**: Due reduced wiring complexity the weight of wiring harnesses is reduced upto 20 Kg. This helps reduce costs. For example fueling costs.  
  * **Scale**: Due their high popularity CAN devices are high in demand. this reduces costs through economies of scale.  

2. **Easy Access**
  * **Centralised Diagnostic**
      * One Important property of CAN Protocol is that all messages are broadcasted and it is upto the node to decide whether to accept it or not.  
      * due to this a dianostic device can be connected anywhere in the CAN network and get access to 100 percent of the traffic.  
  * **Silent Data Logging**: Dignostic devices can log data silently i.e. without interfereing in the main CAN communication.  
  * **ECU Flashing**: ECU Flashing CAN be done over CAN network. many high level CAN protocols such as UDS do it.  
  * **Standardisation**: Many CAN devices across manufacturers use common high level protocols. this enhances interoperability.  

3. **Extremely Robust**
  * **Differential Signaling**: Differentials signals have high noise immunity.  
  * **Error Handling**: CAN uses extensive error detection and nodes are configured to re-transmit faulty nodes.  
  * **Confinement**: The nodes internally perform error tracking and a node can temporarily disconnect itself from the CAN bus (bus-off) certain threshoulds are exceeded.  

4. **Efficient**
  * **Arbitration**: In CAN nodes with lower IDs are given higher priority. this ensures that critical messages get higher priority.  
  * **Utilization**: Arbitration ensures that CAN Bus Bandwidth is utilised by allowing the transmission of low priority messages in gaps between high priority message transmissions.  
  * **Speed**: While CAN protocol has lower speed than automotive ethernet, it is still sufficient for much of the automotive applications.
